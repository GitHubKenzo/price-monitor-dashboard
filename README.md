# Price Monitor Dashboard  
# *A lightweight Dash-based dashboard for visualizing product price history and latest scraped prices.*  
# （price-monitor が収集した価格データを可視化する軽量 Dash ダッシュボード）

---

## 📌 Overview / 概要

This dashboard visualizes data collected by the **price-monitor** scraper.  
It provides:

- 📈 Price history graph  
- 🏷 Latest price table  
- 📊 Product-specific view  

（本ダッシュボードは price-monitor スクレイパーが収集したデータを可視化します）

- 価格推移グラフ  
- 最新価格一覧  
- 商品別ビュー  

The dashboard is built with:

- Dash  
- Plotly  
- Pandas  
- SQLite  
- Gunicorn (production)

## 📁 Project Structure / プロジェクト構成

```
price-monitor-dashboard/
├── .env
├── .gitignore
├── .vscode/
│   └── settings.json
├── app.py
├── data_loader.py
```

### Key Files / 主なファイル

| File | Description |
|------|-------------|
| `app.py` | Dash アプリ本体。タブ UI・グラフ・テーブル表示を担当 |
| `data_loader.py` | SQLite から価格履歴・最新価格を読み込む |
| `deploy.sh` | rsync + systemd 再起動によるデプロイスクリプト |
| `requirements.txt` | 必要な Python パッケージ |
| `.env` | 環境変数（現状は KNOWLEDGE_DB_PATH のみ） |

## 🗄 Database / データベース

The dashboard expects the following SQLite file:

```
data/price.db
```

Tables used:

- `products`
- `price_history`

These are generated by the **price-monitor** scraper.

（price-monitor が生成する SQLite DB を参照します）

## 🚀 Running Locally / ローカル実行

### 1. Install dependencies  
（依存パッケージのインストール）

```
pip install -r requirements.txt
```

### 2. Run the dashboard  
（ダッシュボード起動）

```
python app.py
```

Then open:

```
http://127.0.0.1:8050
```
---

## 🛠 Deployment / デプロイ方法

Production deployment uses:

- rsync（差分デプロイ）
- systemd service restart

### Deploy script  
（デプロイスクリプト）

```
./deploy.sh
```

This will:

1. Sync files to `/opt/price-monitor-dashboard`
2. Restart the `price-monitor-dashboard` systemd service

---

## 📊 Features / 機能

### 1. Price History Graph  
価格推移グラフ  
- 全商品の価格履歴を折れ線グラフで表示  
- Plotly によるインタラクティブ表示  

### 2. Latest Price Table  
最新価格一覧  
- 商品名（リンク付き）  
- 販売元ドメイン  
- 最新価格  
- 最終更新日  

### 3. Product-specific View  
商品別ビュー  
- ドロップダウンで商品を選択  
- 選択した商品の価格推移を表示
